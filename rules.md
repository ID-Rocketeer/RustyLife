# RustyLife Project Rules

## Approved Acronyms
To prevent confusion and obfuscation, only use the following approved acronyms in discussions, documentation, and commits:
- **OOM**: Out-Of-Memory
- **CP**: Control Plane
- **DP**: Data Plane

*Do NOT invent new acronyms (e.g., do not use "GoL" for Game of Life). Always use plain text.*
